Pause&Ponder v0.3 — 루틴·알림·Android 위젯 업데이트
2026-10-07

먼저: 현재 웹은 배포되어 잘 동작한다고 사용자 확인을 받았습니다. 이 패키지는 그 위에 추가할 코드이며 운영 DB/배포/휴대폰 설치는 아직 실행하지 않았습니다.

1. 기존 Supabase 프로젝트의 SQL Editor 열기
   supabase/migrations/003_routines.sql 전체를 붙여 넣어 실행합니다.
   schema.sql은 기존 DB에서 다시 실행하지 않습니다. 추가 SQL은 루틴 관련 테이블/함수/정책/Realtime만 만듭니다.

2. ZIP을 풀고 기존 PP-upload Git 폴더에 소스 반영
   .env.local, .git, 기존 개인 설정은 유지합니다. ZIP 안의 android/ 폴더도 포함합니다.
   터미널에서 기존 Git 폴더로 이동한 뒤:
   npm ci
   npm test
   npm run build
   git status
   git add app components lib public supabase tests android package.json package-lock.json README.md HANDOFF.txt PRODUCT_SPEC.md MIGRATION.md TEST_REPORT.md SETUP_CHECKLIST.txt ROUTINES_ANDROID_UPDATE.txt
   git commit -m "Add routines and Android companion widgets"
   git push origin main
   GitHub에 실제 .env 파일이나 키를 추가하지 마세요. 기존 Vercel 환경변수는 그대로 사용합니다.

3. Vercel 재배포 완료 확인
   기존 Root Directory와 Next.js 설정 유지. 새 /api/client-config와 /api/routines가 필요합니다.
   웹 로그인 → 루틴 메뉴 → 약 먹기, 08:00, 원하는 요일, 오늘 시작, 알림 켜기 → 등록.
   생각함 메인에 오늘의 루틴이 나타나는지, 완료/미룸/기록이 다른 열린 기기에도 반영되는지 확인합니다.

4. Android 앱
   앱은 Android 8 이상. 같은 Supabase 이메일·비밀번호로 로그인합니다. Google OAuth/매직링크 로그인은 이번 네이티브 버전에 없습니다.
   Android Studio에서 ZIP의 android 폴더를 프로젝트로 열고 SDK 35/JDK 17로 빌드합니다. 기본 서버 주소는 https://pouseponder.vercel.app 입니다.
   터미널: cd android && ./gradlew testDebugUnitTest assembleDebug
   다른 주소를 사용하면 ./gradlew -PappUrl=https://새주소 testDebugUnitTest assembleDebug
   APK 위치 app/build/outputs/apk/debug/app-debug.apk. 개인 테스트용 debug 빌드입니다. Play Store 제출용 서명/배포 설정은 별도입니다.
   휴대폰에 설치 → 로그인 → 알림 허용 → 정확한 시각 알림 설정에서 허용 → 지금 동기화.
   홈 화면 길게 누르기 → 위젯 → Pause&Ponder → 생각함/오늘의 루틴 추가.

5. 실제 기기 확인
   2~3분 뒤 루틴을 만들어 앱을 닫고 알림이 오는지 확인합니다. 완료, 10분 뒤, 건너뛰기를 각각 확인합니다.
   생각함 위젯 → 21000원 우산 구매 → 저장 → 웹 돈 페이지에서 −21,000원 확인. 동일 요청 재시도에서 중복 거래가 없어야 합니다.
   네트워크 끄기 → 메모 저장 → 다시 켜기 → 분류/동기화 확인. 앱 로그아웃은 전송 대기 항목이 있으면 먼저 동기화하도록 안내합니다.
   다른 열린 기기에서 루틴 완료/시간 수정 후 반영, 휴대폰 재부팅 후 알림, 알림 권한 거부 상태도 확인합니다.

6. 동작의 한계
   웹 알림은 지원 브라우저에서 화면을 열어둔 동안만 동작합니다. Safari/Android 브라우저의 미지원 상태에서는 Android 앱 예약 알림을 사용합니다.
   Android 앱이 열린 동안 서버 변경은 Realtime으로 조회합니다. 백그라운드는 OS가 WorkManager를 지연할 수 있어 즉시 동기화가 아닙니다. 이미 캐시된 루틴의 알림은 Android AlarmManager가 예약합니다.
   정확한 알림 권한이 없거나 절전/강제 중지/기기 종료 상태에서는 지연·누락될 수 있습니다. 백그라운드에서 다른 기기가 완료한 기록도 다음 동기화 전까지 알림에 반영되지 않을 수 있습니다.
   오프라인 메모는 저장 즉시 분류되지 않고 연결 후 처리합니다. 10분 미룸은 누른 시각 기준이며 연결 복구 시점부터 다시 10분을 더하지 않습니다.
   위젯 크기는 Android 런처가 결정합니다. 폴더블 외부/내부 화면의 위젯과 알림은 실제 기기 확인이 필요합니다.
   입력은 기기에 암호화해 보관하지만 앱 삭제 시 미전송 입력은 사라집니다. 충돌한 요청은 앱에서 웹 기록 확인 후 대기 요청 삭제·재입력할 수 있습니다.

이 문서와 HANDOFF.txt, TEST_REPORT.md, 전체 소스를 다른 개발 계정에 함께 전달하면 됩니다. 같은 Supabase 프로젝트와 같은 앱 사용자 계정으로 로그인해야 데이터가 이어집니다.
